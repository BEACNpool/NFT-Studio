# Five Small Worlds — BEACN Labs

Five complete interactive studies, created 2026-09-08. **Five original editions minted and confirmed; delivered to $beacnleaks.**

Open index.html for the gallery, or any study/program.html in a current browser.
The apps need no media server, fonts, libraries or account. Sound starts after a gesture.
Use the controls to experiment, read the built-in lessons and export artwork.

- Entropy Oracle: crypto magic 8-ball, draw rules and entropy.
- Turing Garden: paint a Gray–Scott simulation; export/import its exact state.
- Chaos Mirrors: nearly identical double pendulums, energy error and divergence.
- Fourier Forge: draw, reconstruct with harmonics, measure error and hear a derived waveform.
- Hash Cathedral: SHA-256 artwork, bit changes and Merkle proofs.

Each directory contains the exact program.html + compact cover.avif mint candidate,
request.json for the local NFT-Studio MCP helper, verified intent.json, review.html, and the original mint-receipt.json.
poster.png is a larger gallery illustration, NOT an additional mint payload.
The review page opens the content-bound NFT-Studio review; signing requires your wallet.
These programs alter local browser state, not ledger state. All five original editions are confirmed. Review requests create separate copies.

The complete synthetic transaction fixtures fit the observed 16,384-byte limit.
Real inputs, witness counts and protocol parameters can change the result; rebuild for
your wallet. Network fees and minimum ADA apply; the native Studio fee is zero.
