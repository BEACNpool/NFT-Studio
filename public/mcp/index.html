01

Clone and build

Use Node 22.13 or newer. Run these commands in your terminal.

TERMINALFresh repository checkout
git clone https://github.com/BEACNpool/NFT-Studio.git
cd NFT-Studio
npm --prefix mcp ci
npm --prefix mcp run build

Only the MCP package needs its dependencies installed. The build creates mcp/dist/cli.mjs.

02

Connect your agent

Add this local server entry to your agent’s MCP settings. Your client may use a different settings wrapper.

Replace /absolute/path/NFT-Studio with the absolute path to your checkout. Keep the /mcp/dist/cli.mjs suffix.

MCP CONFIGURATION · JSONLocal stdio server
{
  "mcpServers": {
    "beacn-nft-studio": {
      "command": "node",
      "args": [
        "/absolute/path/NFT-Studio/mcp/dist/cli.mjs"
      ]
    }
  }
}

Launch the compiled file with node, as shown. Stdio reserves its output for MCP messages.

Your wallet keeps signing authority.

This MCP needs no model-provider key. Signing keys stay in your wallet; the server does not sign or submit transactions.

Unsigned preparation queries public Cardano protocol parameters. Review the request in Studio before continuing with your wallet.
