# Privacy-redacted historical observations

These records report tests that actually ran at the original timestamps. Their
personal hosting hostname has been replaced with `redacted-host.invalid`. That
reserved placeholder is not a live service and was not tested as one.

Each amended JSON record includes `privacyRedaction`, the scope of the redaction
and the SHA-256 of its original private copy. Test results, content hashes and
measurement timestamps remain unchanged. Original reports and rollback copies are
retained privately. The repository-hosted MCP setup guide describes the current
connection method; historical hosted observations do not certify that method.

Current publication removes identifying URLs and direct evidence links to those
URLs. This does not erase earlier Git commits, forks, downloaded artifacts or
third-party caches. Rewriting public history is a separate operation and can
invalidate immutable evidence references.
