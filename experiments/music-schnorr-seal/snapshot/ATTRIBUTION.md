# Original authorship and licenses

BEACN Labs authored the narrow application profile, integration API and verification harness in this kit. Its original code uses Apache-2.0 ([LICENSE](LICENSE)). That license does **not** relicense the retained upstream material or dependency code.

- **BIP-340**, “Schnorr Signatures for secp256k1,” is authored by Pieter Wuille, Jonas Nick and Tim Ruffing. The pinned original declares status **Deployed** and document license **BSD-2-Clause**. Its original [document](upstream/bip-0340.mediawiki.source.txt), attribution and notice are unchanged. Source: [bitcoin/bips at `09e21036…`](https://github.com/bitcoin/bips/blob/09e21036a4001fe6c9ba65c1d3a39b737768132f/bip-0340.mediawiki). The document's status describes its own specification, not this candidate's admission.
- The BIP-340 **test vectors** are derived from that same repository's `bip-0340/test-vectors.csv`. The original directory [license notice](upstream/BIP340-LICENSE.source.txt) permits BSD-2-Clause **or** MIT **or** CC0-1.0. This kit uses the verification-only data projection under its CC0-1.0 option, while preserving original authorship, source identity and the full upstream choice notice. The only transformation is omission of secret-key and auxiliary-randomness columns, lowercase public hex, typed expected result/index and JSON serialization. All 19 original records and comments are represented. The original CSV hash and byte length are retained; the CSV itself was never written to disk.
- **noble-curves 2.4.0** and **noble-hashes 2.4.0**, by Paul Miller and contributors, use MIT. The upstream [MIT license](upstream/NOBLE-LICENSE.source.txt) is retained; the installed packages also carry their licenses. The exact used npm dependency bytes and SHA-256s are in [evidence/build.json](evidence/build.json), with pinned npm archive integrity in `package-lock.json`. The selected [secp256k1 source](https://github.com/paulmillr/noble-curves/blob/656c4364dffa44c64aa0c49914b8000b278b67a9/src/secp256k1.ts) is retained unchanged as inert evidence. The bundle preserves upstream legal comments. We claim neither authorship of Schnorr verification nor an independent audit of noble.
- **Aiken**, by its upstream authors and contributors, uses Apache-2.0. The exact [runtime source](https://github.com/aiken-lang/aiken/blob/8949565a9969278846ffefe30bc3b892029dd318/crates/uplc/src/machine/runtime.rs) and [license](upstream/AIKEN-LICENSE.source.txt) are retained unchanged. The runtime excerpt is evidence only, not executed source in our browser bundle. Actual tests used the installed Aiken `v1.1.23+8949565` native binary; source pinning is not a reproducible binary-build attestation.
- **NFT-Studio** source snapshots and the canonical Midnight Beacon Music packet remain the work of their existing authors under the repository's Apache-2.0 terms. Exact Studio paths, commit and hashes are in [studio/SOURCES.json](studio/SOURCES.json). The changed-credit packet is a synthetic test derivative, deliberately labeled in its filename; it does not revise or claim a real release credit. Synthetic signature fixtures establish no artist or BEACN identity.
- **CIP-49**, by Koz Ross, Michael Peyton-Jones and Iñigo Querejeta Azurmendi, is cited from the fixed registry commit `05ee6bb05982289dbe00c4187b9d54cf90e2e276`, where it is Active and declares Apache-2.0. This kit links to its primary text and does not include another copy of that document.

Exact retrieval URLs, times, original byte counts and SHA-256s for the seven fetched evidence sources are in [upstream/SOURCES.json](upstream/SOURCES.json). These are the authors' original source notices, not a claim that upstream endorses this application. Any later publication should preserve this attribution, all included source/license files and dependency notices alongside the frozen runtime.
