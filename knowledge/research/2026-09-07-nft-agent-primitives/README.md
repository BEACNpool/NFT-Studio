# NFT and agent primitive source review — 2026-09-07

This dated source review supports the five catalog additions CIP-26, CIP-45, CIP-69, CIP-116 and CIP-170. Read [findings](FINDINGS.md) before using the examined implementations. The catalog stores current research summaries; these files preserve their source evidence and interpretation at admission.

All five entries remain research-only. No inspected implementation was installed or executed, no wallet or identity service was contacted, and no ledger evaluation was performed by this review. Proposed Studio integrations and test cases are design ideas.

The 23 catalog source records were retrieved at immutable commits and re-fetched with matching SHA-256. `candidate-source-evidence.json` maps them to local archives where redistribution was supported. `source-retrievals.json` includes supplemental licenses, code and screened-but-unselected CIP documents. Licensing and attribution are in [ATTRIBUTION.md](ATTRIBUTION.md); source files remain unmodified.

The source audit for the admitted catalog is [SOURCE_AUDIT.json](../../SOURCE_AUDIT.json). The source registry itself is the `sources` array in [catalog.json](../../catalog.json); there is no separate SOURCES.json.

Archived upstream files end in `.source.txt` so TypeScript, bundlers and code formatters do not treat them as project code. Their original repository paths remain in the retrieval records; their bytes and SHA-256 are unchanged. Preserve those bytes when integrating or formatting documentation.
