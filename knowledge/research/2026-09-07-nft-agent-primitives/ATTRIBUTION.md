# Attribution and source handling

New BEACN analysis and validation code follow NFT-Studio's Apache-2.0 license (included as `LICENSE`). Upstream bytes retain their own licenses. Source digests identify unmodified retrieved files; our interpretations appear only in candidate JSON and research documents.

The CIP documents and schemas are CC-BY-4.0. Their full upstream license is archived in `evidence/cips-LICENSE.source.txt`. Authors, immutable source links and retrieval dates are recorded per candidate source. Changes: narrow paraphrases and separate BEACN design notes; archived source files are unmodified. License: https://creativecommons.org/licenses/by/4.0/ .

Apache-2.0 source excerpts/files come from Offchain Metadata Tools, Cardano Foundation Connect with Wallet, Fabian Bormann's Cardano Peer Connect, Intersect MBO Plutus, and the Foundation's CIP-170 frontend. Each examined upstream license is included in `evidence/`; original notices in source bytes remain intact. The Plutus root and plutus-ledger-api NOTICE files are also archived unchanged. No implementation code was modified or incorporated into Studio.

The Token Registry and Reeve Indexer did not have an established repository-root license in the examined trees. Their source bytes are not redistributed in this kit. The CIP-116 tests package declares ISC, but the examined tree has no LICENSE file; its source bytes are also omitted. Immutable links, retrieval times and digests remain available, and the online verifier checks those sources without persisting their contents. This is a provenance limit rather than an assertion about all possible licensing grants.
