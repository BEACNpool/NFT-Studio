# BEACN Payload QR

**Create. Scan. Carry.** A printable small-payload feature in NFT-Studio.

The film follows a real Codex → Android VESPR → Cardano mint, then shows how a different, compact creation can travel inside a printed QR. Its audience is artists and musicians, event/community organizers, and creative teams distributing small digital keepsakes.

Suggested post:

> Create. Scan. Carry. BEACN Payload QR puts a small creation inside a printable code. Made for artists, communities and creative teams. Scan, review and mint in NFT-Studio—then pass the code along.
>
> https://beacnpool.github.io/NFT-Studio/

There are two modes. **Continue on phone** uses an encrypted relay that expires after 15 minutes. **Payload QR** carries a public compact creation request in the code and has no relay expiration. Studio must remain available to open its URL; minting still needs internet, wallet approval and network fees.

Sharing the code shares a creation request. It does not transfer ownership of an existing NFT, grant wallet access, establish a shared scarce collection or guarantee viral growth. Copies in one transaction are units of the same asset, and the closing policy is not a lifetime supply cap.

`POCKET SIGNAL` is the original 365-byte SVG used in the printable demonstration. Its QR contains the full canonical request in a compressed URL fragment. `payload-url.txt`, `pocket-intent.json` and `pocket-signal.svg` allow independent comparison. The code carries public content; it is an unminted example with no custom mint options. The options scene demonstrates an independently configured 37-copy, 7-day request.

Film sources: actual recorded Codex guide, Studio handoff and David's Android VESPR mint of ATM RUNNER; original SVG artwork; deterministic titles and editing. Music reuses the instrumental generated with Google Lyria 3.5 for the original ATM RUNNER production. The recorded handoff QR is expired. The closing QR opens the public Studio.

The portrait film is 48 seconds. On-screen copy is the narrative; there is no spoken narration. Technical and encoded-frame checks are reported separately from human playback approval.
