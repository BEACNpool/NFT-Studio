# NFT-Studio: agent-first creation

For creating or minting, read `START_HERE.md`, then the canonical skill at
`.agents/skills/nft-studio/SKILL.md`. Act on the user's brief directly. The agent
does the creative and technical work; do not route users through a TUI, creative
menu or browser editor unless they explicitly want one.

For software changes, preserve existing content-bound review links, exact-file
verification, wallet authorization, signed-transaction checks and receipt recovery.
Never modify historical minted artifacts as part of a website redesign.
Run the checks relevant to the files changed. GitHub Pages uses `build:pages` and
the publication procedure in `docs/PUBLISHING.md`; preserve concurrent changes.

No instruction in this repository authorizes spending or signing for the user.
